# Changelog

Generated from the iPhone app's release notes, also shown under Tools › What's New. Entries describe implemented changes and do not confirm App Store availability. Mac-specific features are documented separately in the Mac workflow.

## 1.4 (2026-11-12)

### New

- Sync between devices. An optional account syncs projects, tags and entries between your devices, end-to-end encrypted on the device. Calendar subscriptions stay on the iPhone. Includes password change, recovery key, account reset by e-mail and account deletion. (Sidebar › Settings › Account & Sync)
- Sub-projects. Projects / areas can have a parent, to any depth. The project list shows them as a tree; deleting a project moves its sub-projects up one level. (Projects / Areas › Edit › Parent)

## 1.3 (2026-11-03)

### New

- What's New. This list of changes in the sidebar. After an update with new features, it opens once and shows only those. (Sidebar › Tools › What's New)
- Feedback. A short form for problems, ideas and questions that goes straight to the developer and answers with a ticket number (an e-mail stays possible), and a link to the public list of planned and ongoing work. (Sidebar › Tools › Feedback)
- Stop from the Live Activity. The Live Activity and the expanded Dynamic Island show the project name and a Stop button. (Lock Screen and Dynamic Island)
- Swipe to stop. Swipe a running entry from the left edge to stop it, in the entry list and in the sidebar's Running section. (Entries)

### Improved

- Calendar import only when you ask. Completed calendar events are no longer imported at launch. Use Import Completed Events when you want them. (Sidebar › Tools › Calendars)
- Entries across midnight. An entry that runs past midnight is split per day in the monthly overview, the project calendar and the month totals.
- Log completed time. Adding time you already worked has its own visible path and uses the word Duration. (New entry)
- Monthly Overview in Tools. The monthly overview moved to the sidebar's Tools section. (Sidebar › Tools)
- Safer and more readable. Deleting a calendar subscription asks first. Dark-mode rows, sidebar rows and Help icons work at large text sizes.
- New contact address. Support is now apps@cblum.ch. (Sidebar › Tools › About)
- Discard running timers. Swipe a running entry to the left in the sidebar's Running section to discard it immediately without saving. (Sidebar › Running)
- Unsaved changes confirmation. Canceling an entry, project, tag or calendar setup with unsaved changes asks first so work is never lost by mistake.
- Filter choices remembered. Your active project and tag filters in the Entries list stay selected when navigating between sidebar screens. (Entries)

### Fixed

- Editing an entry. The edit screen no longer opens inside a second navigation bar, and its fields keep what you typed.
- Navigation and layout polish. Tag detail and modal sheets now use modern navigation without nested bars, and counter numbers avoid splitting across lines.

## 1.2 (2026-10-26)

### New

- First App Store version. Track time per project and tag, start activities from Siri, widgets and Quick Actions, import completed calendar events, review the month and export everything as CSV.
