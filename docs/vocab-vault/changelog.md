# Changelog

Generated from the app's update history, also shown in Settings › About › What's New. Entries describe implemented changes and do not confirm App Store availability.

## 1.0 (2026-11-03)

### New

- Your own vocabulary. Add word pairs with languages, tags and example sentences, search and filter them, and edit or delete them later. (Words tab)
- Practice with spaced repetition. Practice due words in both directions, typed or multiple choice. Correct answers push the next review further out. (Learn tab)
- Scan word lists. Recognise word pairs on paper or in a photo on the device, check them and import them. Unfinished reviews are kept until the next launch. (Scan tab)
- Streaks, XP and statistics. A daily target, streaks, XP and a monthly count of learned words. (Stats tab)
- CSV import and export. Import word pairs from a CSV file without duplicates and export your list. A CSV file is not a complete backup. (Settings › Data & Backup)
- What's New. This list of changes. After an update with new features, it opens once and shows only those. (Settings › About)
- Feedback & development. A short form for problems, ideas and questions that goes straight to the developer and answers with a ticket number (an e-mail stays possible), and a link to the public list of planned and ongoing work. (Settings)

### Improved

- Discard confirmation and filter reset. Closing word forms with unsaved changes now asks for confirmation to prevent accidental data loss. Filtered vocabulary lists offer a quick reset button, and empty monthly learning stats display helpful guidance. (Words tab & Stats tab)

### Fixed

- Standard close button in informational sheets. Informational sheets (About, What's New, Storage Details) now use the standard close button instead of text buttons. (About, What's New, Storage Problem)
