# Feedback and development

Report problems and ideas in the public tracker, or write to [apps@cblum.ch](mailto:apps@cblum.ch) without a GitHub account. German is welcome.

- [Open issues for Rapid Reminders](https://github.com/CyrilBlum/app-feedback/issues?q=is%3Aopen+label%3A%22app%3A+Rapid+Reminders%22)
- [Being worked on](https://github.com/CyrilBlum/app-feedback/issues?q=is%3Aopen+label%3A%22app%3A+Rapid+Reminders%22+label%3A%22status%3A+in+progress%22)
- [Closed issues](https://github.com/CyrilBlum/app-feedback/issues?q=is%3Aclosed+label%3A%22app%3A+Rapid+Reminders%22)
- [Changelog](changelog.md)

Search existing issues first. To open a new report, use [Report a problem](https://github.com/CyrilBlum/app-feedback/issues/new?template=bug.yml) or [Suggest a feature](https://github.com/CyrilBlum/app-feedback/issues/new?template=feature.yml), which require a GitHub account.

For a problem, describe what you did, what you expected and what appeared instead. Include the app version and whether you were using local or synchronized lists. Use invented example items where possible.

!!! warning "Keep private data out of the tracker"
    Issues are public. Do not include passwords, calendar subscription links, email addresses, other people's usernames or screenshots of personal lists. Send any necessary private details by email and remove information unrelated to the problem.
