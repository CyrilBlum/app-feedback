## Feedback

Problems and feature requests for all apps are tracked publicly in
[CyrilBlum/app-feedback](https://github.com/CyrilBlum/app-feedback/issues).
Anyone can read it. Opening an issue needs a GitHub account; without one,
write to [apps@cblum.ch](mailto:apps@cblum.ch). Reports in German are welcome.
