# Feedback and development

For a question or a report without a GitHub account, write to [apps@cblum.ch](mailto:apps@cblum.ch). The same contact address is in About › Contact & Support. Reports in German are welcome.

Describe what you were trying to do, what happened and the app version you used. For a routing problem, say whether the route source was GPX, Apple Maps, local routing or a straight-line estimate. A public example location can help when it does not reveal a private trip.

- [Open Cycloputer issues](https://github.com/CyrilBlum/app-feedback/issues?q=is%3Aopen+label%3A%22app%3A+Cycloputer%22)
- [Work in progress](https://github.com/CyrilBlum/app-feedback/issues?q=is%3Aopen+label%3A%22app%3A+Cycloputer%22+label%3A%22status%3A+in+progress%22)
- [Changelog](changelog.md)

Reading the tracker needs no account. Opening or commenting on an issue needs a GitHub account.

!!! note "The tracker is public"
    Do not post home addresses, private GPS tracks, exact travel times, account details or screenshots showing personal information. If a file is needed for diagnosis, discuss a private transfer by e-mail first.
