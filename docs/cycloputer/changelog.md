# Changelog

The same changes are listed in the app under About › App Guide › What's New. Entries describe the app version shown; availability depends on the build installed.

## English

### 1.0 (2026-11-03)

#### Added

- Cycling map of Switzerland. A topographic map with relief, contour lines and cycle routes, light and dark, plus a 3D view of the terrain. (Main map)
- Route planning. Plan a route with waypoints, see distance, climb and an elevation profile, and save, import or export it as GPX. (Search and Routes)
- Turn-by-turn navigation. Spoken directions with street names and haptic cues along the planned route. (Route)
- Ride recording. Record a ride with distance, speed and climb; an interrupted recording is restored at the next launch. (Main map)
- Offline maps. Download the map and routing for Switzerland for rides without a connection. (Settings › Offline data)
- What's New. This list of changes. After an update with new features, it opens once and shows only those. (About › App Guide)

## Deutsch

### 1.0 (2026-11-03)

#### Neu

- Velokarte der Schweiz. Eine topografische Karte mit Relief, Höhenlinien und Velorouten, hell und dunkel, dazu eine 3D-Ansicht des Geländes. (Hauptkarte)
- Routenplanung. Sie planen eine Route mit Wegpunkten, sehen Distanz, Steigung und Höhenprofil und speichern, importieren oder exportieren sie als GPX. (Suche und Routen)
- Navigation mit Abbiegehinweisen. Gesprochene Hinweise mit Strassennamen und Vibration entlang der geplanten Route. (Route)
- Fahrten aufzeichnen. Sie zeichnen eine Fahrt mit Distanz, Tempo und Steigung auf; eine unterbrochene Aufzeichnung wird beim nächsten Start wiederhergestellt. (Hauptkarte)
- Offline-Karten. Sie laden die Karte und das Routing der Schweiz für Fahrten ohne Verbindung herunter. (Einstellungen › Offline-Daten)
- Neuigkeiten. Diese Liste der Änderungen. Nach einem Update mit neuen Funktionen öffnet sie sich einmal und zeigt nur diese. (Über die App › Einführung)
