# Feedback and development

Problems and ideas for Pixel Porter are tracked publicly. Anyone can read
them without an account.

- [Open issues for Pixel Porter](https://github.com/CyrilBlum/app-feedback/issues?q=is%3Aopen+label%3A%22app%3A+Pixel+Porter%22)
- [Being worked on right now](https://github.com/CyrilBlum/app-feedback/issues?q=is%3Aopen+label%3A%22app%3A+Pixel+Porter%22+label%3A%22status%3A+in+progress%22)
- [Closed issues](https://github.com/CyrilBlum/app-feedback/issues?q=is%3Aclosed+label%3A%22app%3A+Pixel+Porter%22)

## Report a problem or suggest something

- [Report a problem](https://github.com/CyrilBlum/app-feedback/issues/new?template=bug.yml)
- [Suggest a feature](https://github.com/CyrilBlum/app-feedback/issues/new?template=feature.yml)

This needs a GitHub account. Without one, write to
[apps@cblum.ch](mailto:apps@cblum.ch). German is welcome.

!!! note "Everything in the tracker is public"
    Do not post names, e-mail addresses, server addresses, passwords, photos
    of people or screenshots with personal content. Export the diagnostic log
    only by e-mail, not in an issue.
