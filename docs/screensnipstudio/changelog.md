# Changelog

Generated from the app's canonical change history, also shown in the menu bar's What's New window. Entries describe implemented changes and do not announce distribution availability.

## 1.0.1 (2026-11-03)

### New

- What's New. This window lists every change. After an update with new features, it opens once and shows only those.
- Feedback & Development. A short form in the menu for problems, suggestions and questions that goes straight to the developer and answers with a ticket number (an e-mail stays possible), with a link to the public list of planned and ongoing work.
- Rotate with two fingers. Rotate the canvas with a two-finger trackpad gesture.
- Move text and nudge annotations. Drag text annotations to a new place, and nudge a selected annotation with the arrow keys.

### Improved

- Walkthrough and Settings in German. The walkthrough, the reference manual and all Settings texts are now translated into German; the version shown under About is read from the app.
- Cmd+S saves the opened file. Cmd+S overwrites the image you opened instead of asking for a new name.
- Small images open larger. Low-resolution images open magnified in a larger window.
- Better text editing in shapes. Editing text in speech bubbles and rectangles is more precise.

### Fixed

- License window. The license window of the direct-download edition fits the screen again, shows the app icon and is translated into German.
- Shortcuts use Option+Command. Global shortcuts and the menus use Option+Command, so they no longer clash with macOS.
- Toolbar no longer covers the image. The toolbar keeps its own space at launch and when zooming.

## 1.0 (2026-09-29)

- First version. Capture screenshots and annotate them in layers with arrows, text, shapes, blur, step badges and backdrops; copy, save or export as GIF.
