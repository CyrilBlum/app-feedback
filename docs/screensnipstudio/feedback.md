# Feedback and development

Open **Feedback & Development** from the menu bar or write to [apps@cblum.ch](mailto:apps@cblum.ch). Include the app version, the steps that led to the problem and the result you expected.

The form accepts a message, an optional reply address and optional app, macOS and Mac-model details. It does not automatically attach screenshots or annotations. Read the message before sending and avoid personal content or credentials. A successful submission returns a ticket number. E-mail is available as a fallback.

- [Open ScreenSnipStudio issues](https://github.com/CyrilBlum/app-feedback/issues?q=is%3Aopen+label%3A%22app%3A+ScreenSnipStudio%22)
- [Work in progress](https://github.com/CyrilBlum/app-feedback/issues?q=is%3Aopen+label%3A%22app%3A+ScreenSnipStudio%22+label%3A%22status%3A+in+progress%22)
- [Changelog](changelog.md)

The tracker is public. Do not post names, e-mail addresses, licence keys, storage credentials or screenshots containing personal data. Read access needs no login. Opening an issue needs a GitHub account. Reports in German are welcome.
